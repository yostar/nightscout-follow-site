# Nightscout Follow website

This is a static website. It does not require a build step.

## Publish with GitHub Pages

1. Upload all files in this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The included `CNAME` file configures the custom domain `nsfollow.ymsdynamics.com`. Update the domain's DNS records to point to GitHub Pages before moving traffic from the existing host.
